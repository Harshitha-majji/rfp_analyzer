# RFP Analyzer & Proposal Agent

## Overview
An AI-powered RFP analysis and proposal generation system that uses
organizational memory to improve future proposals.

## Problem
Organizations often reuse previous proposal knowledge manually,
which can lead to repeated mistakes and missed successful approaches.

## Solution
Our system analyzes an RFP, retrieves relevant historical memories,
generates recommendations, and produces a tailored proposal.

## Architecture

RFP
 ↓
RFP Analyzer
 ↓
Hindsight Memory
 ↓
Recommendations
 ↓
Proposal Generator
 ↓
Final Proposal

## Key Features
- RFP document analysis
- Historical memory retrieval
- Memory-based recommendations
- AI proposal generation
- Streamlit interface
- OpenRouter LLM integration
